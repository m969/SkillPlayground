# SkillFlow 技能示例 Demo

独立的浏览器示例应用，使用 JavaScript 版 Game.SkillFlow 驱动代码定义的技能流程，并由 Demo 自己的 Three.js 场景播放视觉效果。VFXTweens 仅用于参考视觉表现，不作为依赖；Demo 不导入它的 runtime，也不加载它的特效 JSON。

目前包含十三个技能模板：

- **蓄力地面冲击**：`Sequence(Delay, Action)` 驱动蓄力与冲击视觉。
- **格挡反击**：`Sequence(WaitEvent, Action)` 等待手动触发的来袭事件，再播放反击视觉。
- **连射飞弹**：`ParallelAll` 并行推进三条错峰发射流程；每个 `Action` 独立创建飞弹视觉，等待全部命中后完成。
- **冰晶箭幕**：`ParallelAll` 同时启动七条直线箭路；冰晶箭沿扇形目标飞行，命中后散成霜纹。
- **疗愈脉冲**：短暂蓄势后释放范围治疗波纹，并播放上升的治愈光点。
- **疾风突进**：能量体沿舞台斜线快速突进，并在终点释放冲击波。
- **守护屏障**：展开半球形能量屏障，维持片刻后收束消散。
- **星陨连携终结技**：蓄力后并行发射两枚星弹，全部命中后释放终结冲击。
- **可打断蓄力**：蓄力时等待来袭事件；触发时反制，超时后释放蓄力冲击。
- **星弧变式连招**：根据上下文中的 `comboRoute`，选择突进或双路飞弹终结。
- **陨星天降**：八枚大型陨星从高空同时坠落，在分散落点引发重击。
- **天火流雨**：二十四枚火流星分三波、每波八枚密集覆盖战场。
- **末日星陨**：三十六枚星陨分三波逐步增强，最后追加范围终结冲击。

技能模板注册在 `src/skills/skill-catalog.js`，每个动作键关联视觉工厂；每次执行中的 Action frame 都会创建并管理独立视觉实例。

## 环境

- Node.js 22.12 或更高版本
- npm

## 运行

在本目录执行：

```sh
npm install
npm run dev
```

页面以 `1/60` 秒固定步长推进 SkillFlow 与视觉模拟。切换到后台时暂停并清空时间累积，返回页面后继续；单帧最多补进 8 个步长，剩余时间在后续帧继续处理。

可在视觉画布上拖动鼠标或单指旋转视角，使用滚轮或双指捏合缩放；视角始终围绕舞台中心，并限制在地面上方。

格挡反击模板开始运行后，点击“模拟敌人来袭”发送 `incoming-attack` 事件；事件目标会进入 SkillFlow 上下文。取消等待中的流程会释放事件订阅。

连射飞弹模板展示并发动作及视觉生命周期：三条分支按固定步长错峰启动，各自播放弹道与命中波纹；只有三个动作全部完成后流程才成功。运行中取消会停止所有已启动视觉，重播会释放前一次运行的视觉资源。

冰晶箭幕是独立设计的冰霜箭术示例：七枚冰晶箭同时沿扇形目标直线发射，各自拥有独立视觉；流程等待全部箭路完成，取消时会停止并释放已启动的视觉。

疗愈脉冲、疾风突进和守护屏障分别展示治疗、位移和防护类技能的视觉与流程生命周期。它们与其他模板一样等待视觉播放完成后结束；运行中取消会停止并释放对应视觉实例。

星陨连携终结技通过 `Sequence` 与嵌套 `ParallelAll` 组织蓄力、双路星弹和最终冲击；只有所有阶段完成后技能才成功。可打断蓄力使用 `Timeout` 限制 `WaitEvent` 窗口，超时分支与事件反制分支互斥，事件订阅会在触发、超时或取消时释放。星弧变式连招通过上下文变量 `comboRoute` 使用 `Switch` 选择终结分支；默认路线为 1，测试覆盖两种路线。复杂技能取消时会停止并释放所有已启动视觉。

陨星天降、天火流雨和末日星陨使用 Demo 自有的高空投射物视觉，每枚投射物都有下坠拖尾和独立落地效果。多波技能必须等待当前波全部命中后才进入下一波；天火流雨共 24 枚、末日星陨共 36 枚，单波最多同时播放 12 枚。落点固定以便稳定复现；取消或重播会停止并释放已创建的投射物视觉。

## 验证

```sh
npm test
npm run build
```

SkillFlow 配置由 `src/skills/skill-catalog.js` 中的模板工厂构造。视觉由 `src/visuals/` 下的类独立实现；技能在所有视觉播放完成后结束，中断时同时取消流程并停止视觉。
